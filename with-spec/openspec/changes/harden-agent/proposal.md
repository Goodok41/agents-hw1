## Why

Учебный агент DemoDesk при обращении к несуществующему документу возвращает неструктурированную ошибку без учёта в итоге, исключение внутри инструмента роняет процесс, а проверка источников не ограничена по числу повторов и может бесконечно «уговаривать» модель в рамках бюджета. Нужно сделать поведение предсказуемым и проверяемым.

## What Changes

- `read_doc` с неизвестным ID возвращает структурированную ошибку `not_found`; ID попадает в `missing_ids`.
- Исключение внутри инструмента превращается в результат `{"error": {"code": "tool_failure"}}`, цикл продолжается в рамках лимитов.
- Журнал: у каждого события `tool` есть `status` (`ok`/`error`); в результате появляются `read_ids`, `missing_ids`, `tool_errors`.
- Проверка источников: ответ не может ссылаться на ID, не прочитанный успешно; замечание модели не более 2 раз, затем `stop_reason = "unverified_sources"`, `answer = null`.
- Лимиты вызовов модели и инструментов не ослабляются.
- Интерфейс `search_docs`/`read_doc` и поведение `--replay` сохраняются.
