# Proposal: harden-agent

## Why

Учебный агент DemoDesk (`agent.py`) отвечает по корпусу `docs.json`, но:

- неизвестный `doc_id` возвращает ошибку, которая нигде не учитывается в итоговом результате;
- исключение внутри инструмента роняет весь процесс;
- в журнале нет статуса вызова инструмента, а в результате — списка реально прочитанных и ненайденных документов;
- проверка источников распознаёт ссылки только в виде `[D01:..]`/`(D01)` и повторяет замечание модели без ограничения
  (до исчерпания бюджета), а затем возвращает лишь `budget_exhausted`, не называя причину.

Нужно явно обработать отсутствующий документ и сделать проверку источников ограниченной и прозрачной,
не ослабляя лимиты и не меняя интерфейс инструментов и поведение `--replay`.

## What Changes

- `read_doc` для неизвестного ID возвращает структурированную ошибку `not_found` с этим ID; ID попадает в `missing_ids`.
- Любое исключение внутри инструмента превращается в результат `{"error": {"code": "tool_failure", ...}}`; цикл продолжается в пределах лимитов.
- Каждое событие `tool` в трассе получает `status` (`ok`/`error`); итоговый результат всегда содержит `read_ids`, `missing_ids`, `tool_errors`.
- Проверка источников: финальный ответ не может ссылаться на ID, который не был успешно прочитан. Замечание с конкретными ID возвращается модели не более 2 раз за запуск; при следующем нарушении — `stop_reason = "unverified_sources"`, `answer = null`.
- Лимиты `max_model_calls`/`max_tool_calls` сохраняются: исчерпание даёт `budget_exhausted`/`tool_budget_exhausted` и `answer = null`.
- Интерфейс `search_docs`/`read_doc` и поведение `--replay` по умолчанию не меняются.
- Добавляются тесты `tests/test_agent.py` (unittest, без сети, заглушка модели) по проверкам A1–A5 и регрессии `--replay`.

## Capabilities

### New Capabilities

- `agent`: цикл агента DemoDesk — вызовы инструментов, обработка ошибок, журнал, проверка источников, лимиты и режим `--replay`.

### Modified Capabilities

(нет — ранее спецификаций в `openspec/specs/` не было)

## Impact

- Код: только `agent.py` (функции `run_allowed_tool`, `run_agent`, вывод в `main`).
- Новый файл тестов `tests/test_agent.py`.
- Формат итогового JSON (`--output`) расширяется полями `read_ids`, `missing_ids`, `tool_errors`; новое значение `stop_reason = "unverified_sources"`.
- Без новых зависимостей; сеть в тестах не используется.
