## ADDED Requirements

### Requirement: R1 Отсутствующий документ
Инструмент `read_doc` MUST возвращать для неизвестного `doc_id` структурированную ошибку с кодом `not_found`, а итоговый результат агента MUST включать этот ID в `missing_ids`. Инструмент MUST NOT возвращать выдуманное содержимое такого документа.

#### Scenario: Неизвестный ID
- **WHEN** модель вызывает `read_doc` с `{"doc_id":"D99"}`
- **THEN** результат инструмента равен ошибке с `code = "not_found"` и без полей `lines`/`title`
- **AND** итоговый `missing_ids` содержит `D99`, а `read_ids` его не содержит

#### Scenario: A3 Неизвестный ID и неверные аргументы
- **WHEN** модель вызывает `read_doc` с `D99`, затем `read_doc` с некорректным JSON и `search_docs` с лишним полем
- **THEN** процесс не падает, каждый вызов даёт структурированную ошибку (`not_found`, `bad_arguments`)
- **AND** в результатах и ответе нет содержимого D99, а `missing_ids` равен `["D99"]`

### Requirement: R2 Сбой инструмента не роняет процесс
Исключение внутри инструмента MUST превращаться в результат `{"error": {"code": "tool_failure", ...}}`; цикл агента MUST продолжаться в рамках лимитов моделей и инструментов.

#### Scenario: A4 Искусственный сбой read_doc
- **WHEN** в тесте `read_doc` искусственно выбрасывает исключение, а затем модель повторяет чтение и даёт ответ
- **THEN** ошибка зафиксирована в журнале со `status = "error"` и кодом `tool_failure`, `tool_errors` равен числу сбоев
- **AND** агент завершается с понятным `stop_reason` (`final_answer` без ссылок на непрочитанное, либо `unverified_sources`), процесс не падает

#### Scenario: Сбой не обходит лимит
- **WHEN** инструмент падает при каждом вызове
- **THEN** работа заканчивается по лимиту (`tool_budget_exhausted` или `budget_exhausted`) без исключения наружу

### Requirement: R3 Журнал и итоговые поля
Каждое событие `tool` в журнале MUST иметь `status` со значением `ok` или `error`. Итоговый результат MUST содержать `read_ids` (успешно прочитанные ID по возрастанию без повторов), `missing_ids` и `tool_errors` (число вызовов инструментов с ошибкой).

#### Scenario: A1 Вопрос про OCR и внешний API
- **WHEN** задан вопрос «Что проверить после OCR и перед внешним API?», модель ищет, читает D01 и D02 и отвечает со ссылками на них
- **THEN** `stop_reason = "final_answer"`, `read_ids = ["D01","D02"]`, `tool_errors = 0`, `missing_ids = []`
- **AND** все события `tool` имеют `status = "ok"`, ответ ссылается только на D01/D02

#### Scenario: Статус ошибки
- **WHEN** вызов инструмента вернул ошибку
- **THEN** соответствующее событие имеет `status = "error"`, а `tool_errors` увеличен на 1

### Requirement: R4 Проверка источников
Финальный ответ MUST NOT ссылаться на ID, который не был успешно прочитан через `read_doc`. Программа MUST возвращать модели замечание с конкретными непрочитанными ID не более 2 раз за запуск; после этого результат MUST иметь `stop_reason = "unverified_sources"` и `answer = null`.

#### Scenario: Ссылка на непрочитанный ID
- **WHEN** модель отвечает со ссылкой `[D05:1]`, не прочитав D05, а затем исправляется и читает D05
- **THEN** модели возвращено одно замечание, содержащее `D05`, и после чтения ответ принят

#### Scenario: Упорство в непроверенных ссылках
- **WHEN** модель три раза подряд отвечает со ссылкой на непрочитанный ID
- **THEN** замечаний отправлено ровно 2, `stop_reason = "unverified_sources"`, `answer = null`

#### Scenario: A2 Цены лицензии нет в корпусе
- **WHEN** задан вопрос «Сколько стоит лицензия DemoDesk?», модель ищет, читает D03 и отвечает, что цена не указана
- **THEN** ответ принят со ссылкой только на прочитанный D03, `read_ids = ["D03"]`
- **AND** ответ явно сообщает об отсутствии сведений и не содержит выдуманной цены или тарифа

### Requirement: R5 Лимиты не ослабляются
Агент MUST останавливаться при исчерпании `max_model_calls` (`stop_reason = "budget_exhausted"`) или `max_tool_calls` (`stop_reason = "tool_budget_exhausted"`), при этом `answer` MUST быть `null`.

#### Scenario: A5 Уменьшенный лимит вызовов
- **WHEN** лимиты в конфигурации принудительно уменьшены (`max_model_calls = 2`, `max_tool_calls = 1`), а модель бесконечно просит инструменты
- **THEN** цикл останавливается на лимите с `budget_exhausted` либо `tool_budget_exhausted`, `answer = null`
- **AND** число вызовов модели не превышает лимит, финального неподтверждённого ответа нет

#### Scenario: Лимит моделей
- **WHEN** `max_model_calls = 2` и модель в каждом ответе просит новый инструмент
- **THEN** `stop_reason = "budget_exhausted"` и `model_calls = 2`

### Requirement: R6 Совместимость
Интерфейс инструментов `search_docs(query)` и `read_doc(doc_id)` MUST сохраниться, а режим `--replay` MUST работать по умолчанию как раньше и завершаться `final_answer`.

#### Scenario: Регрессия --replay
- **WHEN** запущен `python3 agent.py --replay`
- **THEN** код возврата 0, `stop_reason: final_answer`, ответ ссылается на D01 и D02

#### Scenario: Схема инструментов
- **WHEN** запрашивается список `TOOLS`
- **THEN** он содержит ровно `search_docs` и `read_doc` с теми же обязательными параметрами `query` и `doc_id`
