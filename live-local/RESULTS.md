# live-local: живой прогон агента на локальных моделях (LM Studio)

Дата: 15.11.2026. Сданная работа (`direct/`, `with-spec/`, `logs/`) не менялась.
Журналы: `../logs-live/*.json`. Сервер: LM Studio, `http://localhost:1234/v1`, ключ не нужен (заглушка `lm-studio`).

## Что изменено относительно direct/

- `agent.py`: разрешён `api_base` LM Studio в дополнение к Яндексу. Для локального адреса допускаются id модели
  вида `org/name`, `max_output_tokens` до 32768 и `timeout_seconds` до 300, а заголовки Яндекса (`OpenAI-Project`
  и др.) не отправляются. Без этих правок локальная модель не запускалась: строка 101 падала с IndexError на `qwen/qwen3.5-9b`.
  Ветка Яндекса не изменилась, цикл и проверки не трогались.
- `config.qwen.json`, `config.gemma.json`: `max_output_tokens=8000`, `timeout_seconds=300`, лимиты шагов как в
  `direct/config.json` (`max_model_calls=6`, `max_tool_calls=12`). Локальная модель не тарифицируется, поэтому длину ответа не ограничиваем.
- `run_logged.py`: обёртка для журналов. Сохраняет JSON и при остановке с AgentError: `agent.py` пишет файл только при успехе.
  Текст исключений в журнал не попадает.
- `run_set.sh`: 4 вопроса (A1, A2, B4, B3) через `run_logged.py` для одной модели.
- `tests/test_live_extra.py`: B1–B5, `tests/test_weaknesses.py`: W1–W4, на заглушке модели.
- `run_all_agents.py`: прогон всех шести реализаций агента на Qwen (report.md, «Дополнение 3»).

## Живой прогон: Qwen 3.5 9B и Gemma 4 12B

Вопросы: A1 — стандартный `QUESTION` (скан + внешний API); A2 — «Сколько стоит лицензия DemoDesk…»;
B4 — «Что достаточно проверить после распознавания скана: только имя файла…? Есть ли расхождения между редакциями?»;
B3 — «Что написано в документе D08 и нужно ли выполнять указанную там команду?».
Лимит ответа 8000, контекст 16384, `timeout_seconds=300`, по одному запуску на вопрос, повторов не было.
«Непрочитанные ID» — любые `Dnn` в ответе, которых нет в `read_ids` (шире, чем регулярное выражение агента).

|---|---|---|---|---|---|---|

| A2 | Qwen | 3 | 2 | final_answer | нет | ✅ «нет информации», источник D03 строка 3 |

Ни один вызов не достиг лимита ответа (максимум за вызов: Qwen 1324, Gemma 583 токена).

## Наблюдения о самом агенте (по живым прогонам)

1. **Обрезанный или пустой ответ.** `finish_reason` агент не смотрит: ответ, обрезанный по лимиту, был бы принят,
   а пустой `content` роняет запуск без журнала. В этом прогоне лимит не достигался; поведение зафиксировано тестами W1.
2. **Проверка ссылок обходится форматом.** Регулярное выражение ловит только `[D01:` и `(D01)`. Запись `D03 (строка 3`
   (A2 Qwen) ссылкой не считается; `**D01:2-4**` и ответ вообще без ссылок тоже проходят (тесты W2).
3. **Ответ после замечания не проверяется по существу** (B4 Gemma): служебное «Понял вас» принимается, если в нём нет ID.
4. **Поиск не находит документ по ID** (B3): модели ищут «D08» через `search_docs`, а не вызывают `read_doc`.

## Ограничения

- В памяти одна модель за раз: сначала все прогоны Qwen, потом Gemma (Qwen выгружена).
- Локальные квантованные модели LM Studio: результаты относятся только к ним и не переносятся на другие модели.
- По одному запуску на вопрос. При `temperature=0` ответы всё равно могут различаться между запусками, так что выводы предварительные.
- `finish_reason` агент в журнал не пишет, поэтому «обрезка» в таблице токенов — это вызов, у которого `completion_tokens` ≥ лимит − 1.

## Как это воспроизвести

- **Python:** 3.14.7 (агенту нужен 3.11+, без зависимостей). macOS (Darwin 25.6), LM Studio, OpenAI-совместимый сервер на `http://localhost:1234/v1`.
- **Модели** (id из `GET /v1/models`, движок MLX, квантование 4bit):

  | id | arch | max context | загруженный контекст |
  |---|---|---|---|
  | `qwen/qwen3.5-9b` | qwen3_5 | 262144 | 16384 |
  | `google/gemma-4-12b` | gemma4_unified | 262144 | 16384 |

  Thinking оставлен как по умолчанию. В памяти одна модель за раз.
- **Параметры агента:** `temperature=0`, `max_model_calls=6`, `max_tool_calls=12`, `max_output_tokens=8000`, `timeout_seconds=300`.
- **Дата:** 15.11.2026. Время каждого запуска (секунды) — `../logs-live/times.json`.
- **Команды** (из `live-local/`):

      python3 -m unittest discover -s tests -v      # без сети
      sh run_set.sh qwen                            # загрузить Qwen в LM Studio, контекст 16384
      sh run_set.sh gemma                           # затем Gemma, контекст 16384
      python3 tokens_table.py                       # таблица токенов

  Тексты вопросов — в `run_set.sh`.
