# live-local: живой прогон агента на локальных моделях (LM Studio)

Дата: 15.11.2026. Сервер: LM Studio, `http://localhost:1234/v1`, ключ не нужен (заглушка `lm-studio`).
Журналы: `../logs-live/*.json`. Сводка и выводы — в `../report.md`, раздел «Живой прогон на локальных моделях».

## Что здесь
- `agent.py`, `config.json`, `docs.json` — копия `../direct/` с минимальной правкой для LM Studio (`local.patch`):
  разрешён `http://localhost:1234/v1` и id модели вида `org/name`, заголовки Яндекса не отправляются,
  для локального адреса `max_output_tokens` до 32768 и `timeout_seconds` до 300. Цикл и проверки не менялись.
- `config.qwen.json`, `config.gemma.json`: `max_output_tokens=8000`, `timeout_seconds=300`, `max_model_calls=6`,
  `max_tool_calls=12`. Локальная модель не тарифицируется, поэтому длину ответа не ограничиваем.
- `run_logged.py` — обёртка: сохраняет журнал и при остановке с AgentError, без текста исключений.
- `run_set.sh` — 4 вопроса (A1, A2, B4, B3) для одной модели через `run_logged.py`.
- `run_all_agents.py` — все четыре реализации (`direct`, `with-spec`, `opus/direct`, `opus/with-spec`) на Qwen;
  журналы и diff копий — `../logs-live/agents/`. Журналы Qwen для этой копии (`../logs-live/qwen_*.json`) взяты оттуда
  (реализация direct, та же правка).
- `tokens_table.py` — таблица токенов по `../logs-live/*.json`.
- `tests/` — B1–B5 (`test_live_extra.py`), W1–W4 (`test_weaknesses.py`), заглушки `stubs.py`.

## Тесты (без сети)

    python3 -m unittest discover -s tests -v          # 20 тестов, OK (expected failures=11)
    python3 ../acceptance/test_a1_a5.py . -v           # A1–A5: 10/10

`expectedFailure` фиксирует то, чего агенту не хватает (сам агент не дорабатывался): B2 — повтор одинакового вызова,
B3 — ответ «по команде из D08», B4 — ответ только по устаревшей D05, B5 — длина вопроса в `run_agent`,
W1 — обрезанный/пустой ответ, W2 — формат ссылок и ответ без ссылок, W3 — служебный ответ после замечания,
W4 — поиск по ID. Подробно — `../report.md`, Таблицы 3 и 4.

## Как воспроизвести
- Python 3.14.7 (агенту нужен 3.11+), macOS (Darwin 25.6), LM Studio.
- Модели (MLX, 4bit, thinking по умолчанию, в памяти одна модель за раз):
  `qwen/qwen3.5-9b` и `google/gemma-4-12b`, загруженный контекст 16384.
- `temperature=0`, по одному запуску на вопрос.

      sh run_set.sh qwen                  # Qwen загружена в LM Studio
      sh run_set.sh gemma                 # затем Gemma
      python3 tokens_table.py

  В этом репозитории журналы Qwen сняты `run_all_agents.py`, журналы Gemma — `run_set.sh`-командами через `run_logged.py`.
  Время каждого запуска (секунды) — `../logs-live/times.json`.
