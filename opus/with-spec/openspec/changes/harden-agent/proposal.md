# Proposal: harden-agent

## Why

Учебный агент DemoDesk (`agent.py`) сейчас плохо переносит сбои и слабо проверяет источники:

- отсутствующий документ возвращается как ошибка `not_found`, но в итоговом результате это никак не видно;
- исключение внутри инструмента роняет весь процесс;
- в журнале у событий инструментов нет статуса, а в итоговом результате нет сводки по прочитанным, отсутствующим документам и ошибкам;
- замечание о непрочитанных источниках возвращается модели неограниченно (до исчерпания бюджета), без конкретных ID, и нет отдельной причины остановки для неподтверждённого ответа.

Нужно явно обрабатывать отсутствующие документы и проверять источники, не ослабляя лимиты и не ломая режим `--replay`.

## What Changes

- R1. `read_doc` с неизвестным `doc_id` даёт структурированную ошибку `not_found`; ID попадает в `missing_ids` итогового результата.
- R2. Исключение внутри инструмента превращается в результат `{"error": {"code": "tool_failure", ...}}`; цикл продолжается в рамках лимитов.
- R3. Каждое событие `tool` в журнале получает `status` (`"ok"` или `"error"`). Итоговый результат содержит `read_ids` (по возрастанию), `missing_ids` и `tool_errors`.
- R4. Финальный ответ не может ссылаться на ID, который не был успешно прочитан. Замечание с конкретными ID возвращается модели не более 2 раз за запуск; затем `stop_reason = "unverified_sources"`, `answer = null`.
- R5. Лимиты не ослабляются: `budget_exhausted` / `tool_budget_exhausted` с `answer = null`.
- R6. Интерфейс `search_docs` / `read_doc` и поведение `--replay` по умолчанию сохраняются.
- Добавляются тесты `tests/test_agent.py` (unittest, без сети, заглушка модели).

Сопоставление проверок A1–A5 из change-brief.md (расшифровка в брифе не приведена, принято так):

- A1 — неизвестный `doc_id` → `not_found`, ID в `missing_ids` (R1, R3);
- A2 — исключение в инструменте → `tool_failure`, работа продолжается (R2, R3);
- A3 — ссылка на непрочитанный ID → не более 2 замечаний, затем `unverified_sources` (R4);
- A4 — исчерпание вызовов модели → `budget_exhausted`, `answer = null` (R5);
- A5 — исчерпание вызовов инструментов → `tool_budget_exhausted`, `answer = null` (R5).

Регрессия `--replay` проверяется отдельно (R6).

## Impact

- Код: `agent.py` (`run_allowed_tool`, `run_agent`); CLI-интерфейс и формат вывода `--replay` не меняются.
- Итоговый JSON (`--output`) получает новые поля `read_ids`, `missing_ids`, `tool_errors`; события `tool` — поле `status`; новая причина остановки `unverified_sources`.
- Новые файлы: `tests/test_agent.py`. Зависимости не добавляются.
