## Context

`run_agent` в agent.py уже ограничивает циклы и проверяет прочитанные источники по тексту ответа.

## Decisions

- Статус вызова: `ok`, если в результате нет ключа `error`, иначе `error`.
- Исключения ловятся вокруг вызова `run_allowed_tool`; в результат попадает только имя типа исключения, не текст.
- Итоги журнала считаются одной функцией по trace, чтобы не расходиться с событиями.
- Замечание модели при непрочитанных ID называет эти ID; счётчик замечаний ограничен константой 2.
- Все ветки возврата `run_agent` собираются в одну функцию, чтобы поля результата были одинаковы.

## Risks

Живая модель может не выполнить замечание: это ограничено двумя попытками, затем явный статус.
Живая модель в тестах не используется.
