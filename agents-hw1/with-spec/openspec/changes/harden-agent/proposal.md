## Why

Учебный агент DemoDesk должен честно вести себя при отсутствующих документах и сбоях инструментов:
не выдавать неподтверждённый ответ и оставлять в журнале проверяемые факты.

## What Changes

- Явная обработка отсутствующего документа (`not_found`) с учётом таких ID.
- Сбой инструмента превращается в структурированную ошибку, процесс не падает.
- Журнал получает статус каждого вызова и итоги: прочитанные ID, отсутствующие ID, число ошибок.
- Проверка источников: ответ со ссылкой на непрочитанный ID не принимается; число замечаний модели ограничено.

## Impact

Меняется только `agent.py` (цикл `run_agent`) и добавляются тесты A1-A5.
Вне объёма: новые инструменты, сеть, изменение корпуса, качество живой модели.
